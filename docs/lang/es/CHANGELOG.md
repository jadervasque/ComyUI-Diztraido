## [0.1.0] - 2026-07-27

### Añadido

- Primera publicación en Comfy Registry con el ID inmutable `diztraido-nodes` y el publisher `diztraido`.
- Publicación automatizada en el Registry mediante GitHub Actions cuando `pyproject.toml` cambia en `master`.
- Filtrado del paquete publicado mediante `.comfyignore`.
- Traducciones al portugués de Brasil y al español en `docs/lang/`.
- Navegación entre idiomas en el encabezado de cada archivo público de documentación.
- Plan de profesionalización en `PLAN0.md`.
- Documentación de arquitectura, desarrollo y catálogo de nodos en `docs/`.
- Directrices de contribución, código de conducta y política de seguridad.
- Plantillas para issues y pull requests.
- Integración continua para compilación y pruebas.
- Configuración de Dependabot para GitHub Actions.
- Estándares del editor, atributos de Git y configuración de herramientas de Python.
- Aviso explícito de derechos de autor y ausencia de una licencia permisiva.

### Cambiado

- El inglés pasa a ser el idioma canónico de la documentación oficial.
- README reorganizado en torno a instalación, características, documentación, mantenimiento e instalación desde el Registry.
- `pyproject.toml` ahora declara los metadatos del proyecto y la versión `0.1.0` para Comfy Registry.
- `.gitignore` ampliado para artefactos de Python, editores, sistemas operativos y datos locales de ejecución de ComfyUI.
